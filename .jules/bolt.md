## 2024-05-15 - Fast AES-CTR Counter Increment
**Learning:** In cryptography routines like AES-CTR mode where a 128-bit counter is incremented per 16-byte block, iterating over the entire 16-byte array on every increment wastes cycles. Since 255/256 times the carry stops after the first byte, an early exit condition `while (n && c)` significantly optimizes the operation. Furthermore, because the counter in CTR mode is a public sequence and not a secret key, introducing a variable-time operation here does not create a security vulnerability (timing side-channel) concerning the plaintext or key.
**Action:** When reviewing multi-byte increment routines (especially for counters and nonces), look for missing early-exit conditions that check if the carry is zero, provided the value is not a secret whose timing would leak sensitive data.
