## 2024-10-24 - Avoid redundant time arithmetic in IPC paths
**Learning:** In the airplay2-win codebase, `xdw_get_sys_time_ms` (which actually computes microseconds despite the `_ms` suffix) is a hot path used for IPC messaging (`xdw_socket_post`). It performs redundant arithmetic by splitting the raw epoch time into seconds and microseconds (via division and modulo) only to immediately recombine them before returning. Furthermore, it uses the slower, two-step `GetSystemTime` + `SystemTimeToFileTime` combination instead of `GetSystemTimeAsFileTime`, which is less efficient.
**Action:** When computing time in hot paths, return the raw time unit directly to eliminate unnecessary CPU cycles. In Windows C/C++ development, prefer calling `GetSystemTimeAsFileTime` directly, but ensure to preserve legacy Windows CE fallbacks (e.g., using `#if defined(_WIN32_WCE)`) since Windows CE does not define `GetSystemTimeAsFileTime`.
