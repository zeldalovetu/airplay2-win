## 2024-09-04 - [Performance Improvement in GetSystemTimeAsFileTime]
**Learning:** The `xdw_get_sys_time_ms` function currently calls `GetSystemTime` and `SystemTimeToFileTime` which takes unnecessary calendar math overhead. Also it does a lot of math to get microseconds and immediately re-combine them. `GetSystemTimeAsFileTime` directly returns system time as a `FILETIME`, which is more efficient. We should still preserve legacy Windows CE support fallback where appropriate but use `GetSystemTimeAsFileTime` in the general case. And we can just return the calculated microsecond time directly rather than unpacking into `tv_sec` and `tv_usec` and then repacking it.
**Action:** Replace `GetSystemTime` and `SystemTimeToFileTime` with `GetSystemTimeAsFileTime` under `#if !defined(_WIN32_WCE)` and return the calculated microseconds `t` directly.
